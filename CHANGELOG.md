# Changelog

## 0.1.0

- Status bar usage for the 5-hour and 7-day windows, with reset times.
- Compact and extended views (`claudeUsage.extendedView`).
- Warning colors at 70 % and 90 %.
- Shared cache between windows, exponential backoff on HTTP 429.
- Refresh command and `claudeUsage.refreshInterval` setting.
